Ambient Capture

Takes a highly volatile snapshot of the invisible "radio room" around you, capturing Wi-Fi routers, BLE beacons, and ambient acoustic room entropy.

🔐

Cryptographic Sealing

Mathematically hashes the exact combination of localized spatial data into an undeniable digital anchor that cannot be spoofed after the fact.

🏛️

Time Authority Lock

Transmits the hash to an internet Time Authority (FreeTSA) to generate an RFC 3161 Timestamp, locking the chain of custody permanently.

Configuration

Documentation on usage, zero-footprint constraints, and offline keys.

Zero-Footprint Constraint

The core program confines every application-created artifact directly to your working directory (e.g. a Forensic USB Drive).

# Evidence Database
./digital_alibi.sqlite

# RFC 3161 Timestamp Tokens
./tsr/<capture-id>.tsr

# Local Offline Signing Keys
./digital_alibi_ed25519_private.pem
./digital_alibi_ed25519_public.pem

Advanced CLI Commands

Run the tool continuously in a highly volatile environment (airport, coffee shop) using the watch command to snapshot every 60 seconds.

$ ./DigitalAlibi-linux-x86_64 watch --interval 60

Standard commands:

capture [--tsa-url HTTPS_URL] [--no-tsa] [--ble-seconds N] [--capture-id ID] [--note TEXT]
flush [--limit N]
